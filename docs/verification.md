테스트에는 다음 사례가 포함됩니다.

- 서로 다른 가로·세로 배율과 4점 원근 투영, 퇴화한 보정 좌표
- stride 적용 시 프레임 번호·시간·EOF 일관성
- 빈 추적 결과, 짧은 경로, 같은 시각의 관측, 역방향·정지·오래된 경로
- 음수 crop 좌표와 빈 이미지, 분류 배치 수·확률·클래스 순서 오류
- 미래 관측 제외, 관측 누락 시 외삽, 최대값 선택 후 올림
- 가상 모델을 연결한 전체 파이프라인과 손상·짧은 영상 오류
- YOLO 어댑터의 텐서 변환 계약과 결과 영상의 출력 FPS·속도 단위·자원 해제

YOLO 어댑터와 영상 출력 검증에는 테스트 대역을 사용했습니다.
실제 YOLO 또는 실제 영상 코덱을 통과한 실행을 뜻하지 않습니다.
